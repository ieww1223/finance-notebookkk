# Jiji 的金融筆記本 📒

政大金融系課程筆記網站。把投資學、金融機構管理、金融法規中的觀念，整理成「一個觀念一頁」的白話筆記，並收錄真實的市場事件。

- 網站：GitHub Pages（見 repository 右側 About 的網址）
- 規則：所有專案規則寫在 [AGENTS.md](./AGENTS.md)，讓 AI 可以照同一套格式持續新增筆記。

## 如何新增一篇筆記

對 AI 說：

> 請先讀 AGENTS.md，然後新增一篇「夏普比率」的筆記。

AI 會依照 AGENTS.md 的 SOP：複製模板 → 填入固定 8 個區塊 → 登記到 `data/notes.js` → 更新 `log.md` → 自我檢查。
